## Visual & funcionamento

- As imagens de estatísticas são geradas automaticamente por um workflow GitHub Actions e salvas em `assets/`. Isso elimina imagens externas que podem falhar.
- O banner é um SVG local (`assets/banner.svg`) que contém estilo visual (neon/glow) — equivalente a aplicar CSS em uma página normal.
- Se as imagens ainda não aparecerem, rode o workflow manualmente (Actions → Generate stats → Run workflow). Ele vai criar os SVGs e o README passará a renderizar corretamente.
